## 官方调研依据

调研日期：2026-10-19。以下均实际打开官方页面或官方仓库正文。产品文档未标注统一发布日期，以访问日期记录；动态网页和源码默认分支不是固定发布版本。本轮用于交互参考，不构成设备兼容或算法性能证据，也不决定框架或依赖。

- R1：TopHatch / Concepts，未标日期，[*Brushes and Tools*](https://concepts.app/en/manual/brushes-and-tools)。Dynamic Pen 按压力改变笔宽，Fixed Width Pen 恒宽；工具提供笔宽、透明度与平滑参数。Slice 切除路径，Mask 遮挡内容。页面包含官方效果示例。自定义笔刷编辑部分标为 iOS 能力，不能据此推定双端支持。
- R2：Krita 文档团队，5.3.0 文档，[*Freehand Brush Tool*](https://docs.krita.org/en/reference_manual/tools/freehand_brush.html)。无平滑响应最快；稳定器会使笔迹落后光标，路径与压力平滑有不同设置。用于提出延迟、转折和抬笔尾部验收。
- R3：Xournal++ 项目，未标日期，[*Eraser tool*](https://xournalpp.github.io/guide/tools/eraser/)。区分 Standard 局部擦除、Delete Stroke 整笔删除和 Whiteout 覆盖。ThinkPaint 的局部擦除需要真实几何缺口，不能以白色覆盖代替。
- R4：Krita 文档团队，5.3.0 文档，[*Pop-up Palette*](https://docs.krita.org/en/reference_manual/popup-palette.html)。弹出工具盘集中放置颜色、最近颜色与画笔预设，作为布局候选 B 的参考。
- R5：Krita 文档团队，5.3.0 文档，[*Tablet Settings*](https://docs.krita.org/en/reference_manual/preferences/tablet_settings.html)。区分鼠标与触笔事件及压力测试，并记录平台输入问题；本项目需独立验证实际型号与驱动。
- R6：tldraw，未标日期，[*Bindings*](https://tldraw.dev/sdk-features/bindings)。形状几何与绑定记录分开，解绑相关回调可将当前连接位置写回端点；作为解除绑定不跳位的参考。
- R7：tldraw，未标日期，[*Draw shape*](https://tldraw.dev/sdk-features/draw-shape)；Excalidraw 项目，动态主分支，[*元素类型源码*](https://raw.githubusercontent.com/excalidraw/excalidraw/master/packages/element/src/types.ts)、[*绑定源码*](https://raw.githubusercontent.com/excalidraw/excalidraw/master/packages/element/src/binding.ts)。可核对点、压力与绑定数据的分工。tldraw 的 draw 外观会模拟鼠标压力，ThinkPaint 按既有需求采用鼠标恒宽。Excalidraw 的解绑函数修改原箭头的指定绑定，不能据此推断所有交互的视觉效果。

沿初步方向细化的可见效果和操作：

- 支持压感的笔显示压感开关、响应调整和试写区，轻压细、重压粗。鼠标采用所选恒定宽度。实际压力、侧键或橡皮端缺失时显示能力缺失，不用模拟数据冒充。
- 平滑有关闭及可调强度，并提供轻度/较强快捷入口；具体默认值、算法与参数未定。实时与最终路径采用同一规则，调整下一笔参数不自动改变旧笔迹。强度变化通过相同试写轨迹比较抖动、主要转折、终点与延迟。
- 橡皮显式切换“整笔”和“局部”，显示作用范围。整笔命中后整笔消失；局部擦过中段后保留可编辑残段。候选目标为可编辑的普通/荧光笔迹；箭头和绑定关系线通过专门选择/编辑处理，具体资格矩阵需 M07/M08 协商。橡皮默认不删除图片和文字，也不穿透隐藏、锁定或当前不可操作内容。
- 箭头提供直线、折线、自由曲线，单向/双向/无箭头，颜色、宽度、虚实与箭头大小。曲线沿末端方向显示箭头；选中显示端点及路径控制点。端点位置重合或极短路径的方向规则尚待制定，不能生成无效几何。
- 候选绑定反馈：自由端点空心、已绑定端点实心，并辅以“起点：自由／终点：图片 A”文字；颜色不作为唯一提示。绑定由 M08 的明确连接操作或可见吸附确认建立；平滑和视觉重叠不建立绑定。解绑端点停在当前画板位置。

## 细项顺序与推进条件

按 M02.01 → M02.03 → M02.02 → M02.04 → M02.05 → M02.06 安排后续细项。先确定画笔效果和鼠标固定宽度基线，再加入真实压力和平滑，再处理切割与线形编辑。基础内容类型、无状态线几何、字段清单和固定样例的文档准备从第一步并行推进，供 M08 提前核对；M02.06 的完整交互仍在基础输入与事务稳定后验收。本轮仅细化文档，后续实现另需授权。

后续实现每步的进入条件是相关接口问题已有主责答复并有真实可调用能力；退出条件是对应细项必要验证通过、结果与未验证能力已记录。可先完成不依赖真实服务的设计；设备、联合操作或格式未就绪时只标该部分待验证，不跳过原验收。

## 联合操作与失败验收安排

- 一次绘制或擦除：输入路由和坐标就绪，在基础快照上保持私有活动预览，抬笔后一次提交。取消无正式变化；提交冲突按既有规则重新规划和展示，不自动提交旧坐标。工具切换、失焦、后台、设备断开、画板切换的完成/取消策略尚需 M10/M07 明确；未确定前不承诺保留半笔。
- 图片批注：M03 指定图片实例，M04/M07 提供变换与归属，M02 生成几何。测试移动、缩放、非等比变换、旋转、翻转、裁剪/恢复、解绑、复制/收纳/撤销；保存重开后落在相同图像位置，擦除不能伤及图片或其他实例。
- 自由线转换关系线：M08 计算指定端的绑定/解绑/重接，M02 计算几何，M07 合成完整事务。核对同一 ObjectId、路径、文字、样式和公共资料；解绑不跳位，移动原目标不再带动已解绑端。取消和失败均不残留半次转换。
- 绑定目标变化或收纳：M07 候选变换经 M08 的纯规则和 M02 无状态线形能力，在提交前补齐几何和绑定。需覆盖单端、双端、绕行曲线、同对象回环与收纳改接；一次撤销恢复全部。隐藏/筛选不改变实际绑定。
- 文字、保存与搜索：M06 组合输入只作临时状态；正式文字和几何经 M07 同事务通知。M09 只保存有效正文版本，M05 从正式资料可重建索引；撤销/重做和部分擦除后再往返，核对对象 ID、资料、字段和显示。
- 工具区与画布：M02 工具区按“工具栏”栏目下方的初步位置接入，M10 提供外壳/焦点，M04 更新有效画布及导航范围。操作工具、调参、展开面板、变更窗口/方向或打开输入法后，核对没有额外落笔、导航没有重复执行、小地图可用、落笔和橡皮位置仍与指针一致；未结束笔画的处理按 Q2 执行。

实际可用型号尚未盘点，本轮没有连接设备或运行功能。下列是需求清单，不能记为硬件已覆盖。

- Windows：真实普通鼠标和键盘；至少一台数位板或笔屏，记录设备/笔型号、Windows 版本、驱动、显示器与系统缩放。测真实压力、悬停、侧键、橡皮端（具备时）、跨屏及窗口边缘坐标、拔插、失焦和修饰键释放。
- Android：真实触屏平板与支持压力的主动笔，记录设备/笔型号、系统、显示刷新率。测笔/手掌/手指共存、手指导航、显式开启手指绘画、侧键/橡皮端（具备时）、多触点、旋转/分屏、后台和系统取消。若只有数位板而无笔屏，屏上笔尖到显示的延迟不能据此宣称已测。
- 固定轨迹：点按、极短线、慢斜线、S 曲线、尖角、快速回环、折返、不同速度、轻重渐变、抬笔立即再落笔。保留设备实际事件和顺序；同一记录分别比较平滑关闭、轻度、较强，真实设备试写另行进行。
- 固定内容：普通/荧光笔与压感粗线交叉，中段擦成多段、端点/全擦、快速扫过和重复擦；混合图片/文字/锁定对象，变换后的附着批注；直线/折线/自由箭头、绕行和回环；正负/远坐标、不同视图比例。
- 事务与文件：检查一个操作一个撤销步骤、取消/冲突/目标失效无部分修改；再编辑、重做、重开及 Android→Windows→Android 往返，比较 ID、压力/宽度、颜色/透明度、路径/控制点、虚实、箭头、文字、归属和绑定。损坏字段与未知版本应报告真实失败。
- 测量办法：先固定真实设备、事件采样方式、显示刷新率、点数、笔迹数、混合对象负载、缩放和重复次数，再与 M04/M10 预先约定通过门槛。分别测笔尖到显示延迟、样本处理与帧耗时、平滑增加的延迟、终点/转角偏差、擦除耗时和内存；记录分布、最大值与丢帧，不能只报平均帧率。
- 比较基线：同设备、同轨迹以关闭平滑为基线，重复测量估计波动，再比较候选强度；轨迹误差与延迟同时达标才采用。事件重放仅验证几何/事务，不代替真实压力、防误触或硬件延迟。当前没有批准的性能数值和任何实测结果。
