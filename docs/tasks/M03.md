## 协作接口需求清单与结果语义

接口名来自管理目录协议 0.1；以下输入输出细节是需求意图，尚未成为新增共享签名。不得跨功能包直接 import，使用共享协议及构造注入。

- M10 / SystemAccessPort、ToolRuntimePort：输入导入入口、OperationContext、工具目标与活动会话；输出系统输入句柄、实际格式资料、成功/取消/错误和工具结束结果。Windows 拖入/粘贴截图，Android 相册/剪贴板/分享分别核对能力。系统取消、失焦、切后台、输入法占用按明确事件处理，不将主动取消记为导入失败。
- M09 / AssetStorePort：输入来源句柄、操作标识与取消信号；输出已完整准备的 AssetRef、图片像素与方向资料、校验结果及读取能力。需协商资源暂存确认、失败回收和引用检查的具体形态；引用保护覆盖存留对象、撤销与恢复。存储失败报告阶段和原因，不产生缺原图对象，也不依赖外部绝对路径。
- M07 / DocumentReadPort、EditorPort：输入同一 SceneSnapshot、SessionId/baseRevision 和图片/批注/归属/端点/线形/资源引用的完整 EditPlan；输出 CommitOutcome、新版本与一次 DocumentChange。预览失效、锁定、目标消失、归属循环或字段冲突时拒绝整项，重新规划并重新确认；成功一次提交、一次通知、一次撤销，不在第二笔编辑补关系。
- M04 / ViewportPort、内容呈现契约：输入会话、屏幕/画板/图片局部坐标、裁剪与对象变换；输出坐标转换、几何边界、命中和聚焦/临时显示结果。M03 贡献图片及盒的 GeometryProvider/ObjectPainter，M04 调度并管理显示缓存。读取/解码在绘制前完成；资源加载失败明确显示，不能把缺图导出记为成功。
- M02 / LineGeometryPort 与绘图贡献：输入同一快照、图像实例目标和局部坐标，或关系端点/回环的几何需求；输出笔迹/箭头内容与几何变更计划。批注绘图通过 M10 唯一活动工具接入；不另存线条身份、路径或文字副本。工具取消与几何失败不提交半条批注；多回环的几何区分由 M02/M08 协作。
- M06 / TextEditingFactory：输入宿主对象标识、原字段值、局部位置和编辑上下文；输出中文编辑提交或取消及文字变更。盒名与图片备注写回既有公共资料，M08 的 MetadataPort 提供相应编辑计划；字段编辑不额外产生独立文字框。图片上独立附着的文字内容仍由 M06 提供。组合输入期间不触发画板快捷键，取消保留正式字段。
- M08 / RelationsPort、MetadataPort：输入同一快照、收纳/拖出/移除意图与图片和盒 ID；输出受影响线 ID、端点原/新目标、回环和移除计划、资料变更计划。保持未受影响端点及线的资料和身份，拖出计划不自动恢复旧连接。无效目标或不兼容几何使整个联合计划失败，不删除或合并回环代替处理。
- M03 / ImagesPort 与类型贡献：向 M04/M05/M07/M09 提供图片与盒查询、planCollect、附着计划、revealObject，以及几何/绘制/版本化编解码/资源引用提取/克隆引用重写/检索资料。输入稳定对象 ID、实际快照及定位目的；输出正式操作计划或可释放的临时展开结果。目标已删除、路径变化、隐藏锁定需重解析并按真实状态报告，不改写旧容器路径。

所有正文变化统一由 M07 发出正式变化流；M09 保存固定版本，M05 消费相同正式资料建索引。界面、临时预览和缩略图不另发可独立修改正文的事件。M03 对搜索的展开行为必须区分持久展开状态与临时查看，具体约定待 M04/M05/M07 协商。

数据与注册交付：M03 描述图片的 AssetRef、原图/方向资料、裁剪、翻转和不透明度，以及盒的封面选择与专用显示数据；字段形态按上表交相关主责确认。ObjectRecord 的稳定 ID、归属、通用变换、顺序及公共资料只由 M07 保存，批注仍是 M02/M06 的正式对象，通过统一归属附着。M03 不建立第二份盒成员或批注归属表。同原图多实例可共享 AssetRef，实例编辑与克隆附着分别使用自己的对象 ID。

图片与档案盒两种内容均须提供 ContentTypeDefinition/ContentUiBinding 对应的数据校验、版本化编解码、资源引用提取、克隆引用重写、检索资料、边界、命中、绘制和编辑预览；UI 贡献使用 M03 命名空间接入 M10。类型注册完整性纳入 M03.03 与 M03.05 的交付，未知类型/版本或缺资源通过 M09 的真实错误路径报告。

结果和取消时点统一要求如下：

- 文件选择/资源准备：成功返回真实句柄或完整 StagedAsset/AssetRef；主动取消用 OperationCancelled；预期文件/存储失败用 StorageFailure，保留文件、阶段、错误码、原因和可重试信息。逐文件失败列表与可用项数量分开显示；本操作结束后到达的回调不得创建对象。
- 编辑预览/提交前：取消仅释放本操作的草稿与暂存引用，正文和端点不变；提交前检查会话及 baseRevision。M07 返回 CommitOutcome：已应用时明确新版本，无变化时不产生新撤销项，版本冲突时重规划并重新确认，校验拒绝时说明具体原因。
- 编辑已应用：界面按实际成功呈现；此后取消窗口或保存操作不能声称编辑已取消，也不能自动反向修改正文。需要退回由明确撤销完成。保存失败保留实际已编辑/未保存状态，展示 M09 失败及对应版本，不把已编辑等同已保存。
- 关系规划与坐标/定位：无效目标、锁定限制、归属循环、几何无法完成或过期请求返回实际失败/拒绝/失效，不返回空成功。新的定位、会话关闭或切换会使旧异步结果失效；只有当前请求可滚动高亮，不改变持久隐藏和锁定。
- 通知与历史：一次已应用完整编辑发出一次正式 DocumentChange 和一个撤销步骤；撤销与重做各产生新 contentRevision。保存与索引消费正式变化，不从预览补写内容。M09 原图引用保护覆盖正文、撤销和恢复，窗口缓存可重建。

## 已定的联合流程约束

这部分沿用现有需求和协议，作为已批准模块方案的硬性约束。跨模块完整操作通过 M07 一次事务提交。

- 收纳：M03 与 M08 在同一快照准备归属、端点与回环几何，界面逐条预览，明确确认后交 M07 一次提交；预览期间内容变化必须重新规划并再次确认。
- 取消和失败：正式对象、父子归属、端点、资源引用全部不应用部分结果。提交成功与保存成功分别报告，M09 不能把旧版本保存回执当作当前版本已保存。
- 完整撤销/重做：同时恢复图片和附着内容的归属、局部变换、盒顺序、线端点、几何、资料和引用；线条稳定 ID 不改变，同盒多条线分别保留。
- 拖出：图片与附着内容返回画板，盒连接留在盒上；重接必须由 M08 的显式操作完成，保存重开保留实际目标。
- 解散与删除：先展示图片处理选择及盒连接影响；仍连接盒的关系随目标移除。解散保留图片并在附近可见区域摆放，连同内容删除包括附着内容；撤销恢复对应完整状态。
