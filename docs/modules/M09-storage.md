# M09 保存与导出

模块分支：`module/storage`。原需求来源：F12 的保存恢复部分、F13，协作支持 F02、F06、F07。

## 代码目录与独立设计

统一采用 Flutter + Dart。计划代码目录为 `packages/thinkpaint_storage/`，公开入口为 `lib/thinkpaint_storage.dart`，私有实现放在 `lib/src/`，本模块验证放在 `test/`。这些代码目录在后续工程任务中建立。

本模块独立设计自己的页面、面板、对话框、工具与局部状态，设计资料按需要放在 `docs/design/M09/`。M10 统一主题、外壳、导航与焦点；模块通过页面、面板、工具和设置贡献接入，具体布局和交互由本模块细化并审阅。

静态依赖只使用两个共享协议包和本模块依赖，功能包之间不互相 import。提供：AssetStorePort、ProjectRepositoryPort、CatalogRepositoryPort、SaveCoordinatorPort、ExportPort。消费：SystemAccessPort、DocumentReadPort、一致内容与视图快照、内容编解码、SceneRenderPort（导出器阶段）。

依据：[技术决定](../architecture/PLATFORM_DECISION.md)、[工程结构](../architecture/PROJECT_STRUCTURE.md)、[共享接口](../architecture/SHARED_CONTRACTS.md)、[模块依赖](../architecture/MODULE_DEPENDENCIES.md)、[独立界面设计](../architecture/UI_DESIGN_GUIDE.md)。

## 职责和接口

本模块负责项目容器、资源文件、格式版本、读写完整性、自动保存、备份恢复、双端传递和图片文档导出。向 M01 提供实际项目创建、打开、复制、回收和恢复服务，向内容模块提供资源接口。

各内容模块提供自己的版本化数据编解码与绘制适配；M07 提供一致对象快照，M04 提供画板呈现能力。本模块不重新实现图片编辑、笔迹、文字或关系逻辑。接口遵循 [模块协作约定](../MODULE_CONTRACTS.md)。

## M09.01 项目格式与对象编解码

**详细功能描述：**记录公开、带版本的项目容器和对象注册方式，组合各模块的专用数据、通用对象状态、关系、容器及必要视图信息。各模块维护自身类型与数据版本，本模块管理项目级版本、校验和迁移。

**验收条件：**全部注册类型可保存往返且语义一致；新旧版本的支持范围和迁移有明确结果；不支持类型或损坏输入明确报错，保留原文件。

## M09.02 图片资源与项目操作

**详细功能描述：**把原图收进项目，允许多个图片对象引用同一资源，保留原始文件。提供创建、打开、复制、导入、画板回收与恢复接口；回收站项目与活动项目状态明确。

删除对象、隐藏、裁剪或解散容器不立即移除仍被引用或用于恢复的资源。物理清理采用独立且明确的操作规则。

**验收条件：**外部原图移动后项目可打开；复制项目独立编辑；同图多实例资源完整；画板回收和恢复保持全部对象和连接，损坏资源明确报告。

## M09.03 自动保存备份与异常恢复

**详细功能描述：**在完整事务后安排自动保存，并处理关闭、切换画板、后台和系统取消事件。结构和资源作为一致状态写入，避免中断后只剩结构或部分图片；保留最近有效版本与必要备份。

保存失败展示原因及真实状态，不能把未写入内容报告为成功。编辑撤销历史属于 M07 的当前会话，历史备份用于重开恢复。

**验收条件：**存储不足、进程退出、写入中断和损坏项目不覆盖最近有效文件；恢复来源清晰；实际保存损失范围满足测试前规定目标；与 M01 切换、M10 生命周期通知联合验证。

## M09.04 双端传递与编辑往返

**详细功能描述：**独立项目包含必要资源及元数据，不依赖设备原始绝对路径。支持在 Windows 和 Android 之间离线复制、导入并继续编辑，公开格式说明可用于备份及工具兼容。

**验收条件：**Windows 创建、Android 编辑、传回 Windows 后，内容、归属、连接、裁剪、批注和资料完整；字体不可用按 M06 提示且不损坏原文；自动云同步与并发编辑不计入本项。

## M09.05 PNG 区域与整板导出

**详细功能描述：**将选中对象、指定区域或整个画板导出 PNG，预览边界、背景、透明选项、分辨率和预计规模。复用各对象呈现能力，支持当前筛选结果或完整内容的明确选择。

**验收条件：**远坐标、透明图片、文字、笔迹、回环和附着批注与预览一致；超出支持规模时明确提示；筛选不静默漏掉应导出的内容。

## M09.06 PDF 分页与导出校验

**详细功能描述：**提供用于打印和汇报的 PDF 导出，预览页面、范围、比例和分页。大范围内容可分成多页，保留正确的文字、图片和关系呈现，并检查导出文件可打开且页数与预览一致。

**验收条件：**跨页内容、线条、背景与装饰按选择输出；两端同一项目的导出语义一致；错误有可操作提示且不会覆盖源项目，取消不留下被误认为成功的文件。

## 模块完整验收

使用全部模块构成的真实画板验证保存、故障恢复、回收恢复、两端往返和 PNG/PDF 导出。单个类型未提供编解码或呈现适配时明确记录待集成，不以空对象或省略内容报告成功。
