# M06 文字与便签

计划分支：`module/text`。需求来源：原 F03，并为 F04、F09、F15 的文字编辑提供协作能力。细分需求编号：M06.01 至 M06.05。

本模块负责可编辑文字框、便签、文字样式、排版和中文输入。它也提供可复用的文字编辑交互，供其他模块编辑各自拥有的名称、备注和标签。

## 职责边界与协作接口

M06 提供文字对象的创建、显示、内容编辑、测量与编辑焦点状态，并通过共享编辑操作记录正式文字变化。文字对象接入 M07 的选择、变换与撤销事务、M04 的坐标和渲染、M09 的保存与导出，以及 M05 的文字检索。

中文输入法的组合输入、候选词与提交由 M06 处理；M10 提供键盘和焦点的标准事件及系统键盘状态，M04 根据编辑区域执行视图避让。临时输入和正式内容的边界必须明确。

自由箭头的标签由 M02 维护，关系线的标签与线索元数据由 M08 维护，档案盒名称和图片备注由 M03 维护。M06 可提供通用文字编辑器，但文字的对象归属、跟随位置和存储资料由所属模块决定，不能生成重复的独立文字框。

共享规则见[模块协作约定](../MODULE_CONTRACTS.md)，需求总览见[项目需求](../REQUIREMENTS.md)，依赖和分支安排见[开发计划](../DEVELOPMENT_PLAN.md)。

## M06.01 中文输入与文字编辑状态

**详细功能描述：**在画板任意位置创建文字框，支持中英文输入法、换行、光标移动、文本选择、复制、剪切、粘贴和常见编辑操作。进入文字编辑时显示清楚的编辑状态，退出后以对象方式选择和移动。

输入法组合输入是选词完成前的临时内容，提交后才形成正式文字。处理候选词确认、组合取消、焦点切换、系统取消和应用进入后台，防止丢字、重复提交或半段临时文字进入项目。

编辑期间文本快捷键和输入法优先于画板工具快捷键。文字编辑使用符合预期的撤销粒度，并与对象级撤销协作；一次输入法提交不会被分裂为每个临时候选词的项目操作。

**验收条件：**

- 双端实际中文输入法完成拼音或其他已记录输入方式的组合、选词、取消和连续输入，正文正确。
- 中文、英文、数字、标点及多行粘贴后，光标、选区和撤销结果一致。
- 输入法工作时按下字母、方向键、确认或删除键，不误触画板绘图、删除对象或导航。
- 双击或规定操作进入编辑，拖动对象外框移动文字框，两者行为可明确区分。
- 失去焦点、后台和系统取消后状态正确结束或保留，不出现持续输入或重复提交。

## M06.02 字体样式与便签外观

**详细功能描述：**文字框提供字体、字号、文字颜色、加粗和对齐设置，以及背景色、边框和内边距。提供透明文字、标题和便签预设，用于说明、区域标题和较长记录。

预设是可继续编辑的文字样式。改变预设或主题时保留正文与明确设置的内容属性；背景和文字保持可读，选中和正在编辑时仍能辨认边界。

文字样式的作用范围在工具界面明确显示。首版以文字框为样式单位，进入编辑后文本选择用于复制、替换和输入；不同字符的混合富文本样式作为独立扩展，不隐式增加格式能力。

**验收条件：**

- 每项提供的样式可修改、撤销、保存重开，并与界面显示一致。
- 透明文字、标题和便签均能继续编辑和变换，不依赖固定背景才能使用。
- 改变便签背景或应用主题后，文字与编辑边界仍可辨认。
- 样式设置始终作用于明确的对象，不因存在文本选区而产生不可预测的局部格式。

## M06.03 文字框尺寸、换行与键盘避让

**详细功能描述：**支持随内容自动扩展和固定宽度自动换行。手动调整框宽时重新排版，保留原文及显式换行。文字测量、可见边界、光标位置、选择范围和命中使用相同排版结果。

Android 屏幕键盘或其他输入面板出现时，报告实际可见编辑区域，由 M04 将光标或正在编辑的文本移到可见范围。避让调整视图，不移动文字对象的画板坐标。键盘关闭后的视图处理采用共享视图规则。

在缩放、旋转和远坐标条件下进入编辑时，坐标转换保持准确，编辑工具与选区不会跳到其他对象。很长的文本仍可滚动或定位到正在编辑的位置。

**验收条件：**

- 两种尺寸模式下的中文长文本、英文长词和显式换行显示正确，无文字内容被截断丢失。
- 改变宽度、缩放或旋转后，实际文字、对象边界与点击位置一致。
- Android 键盘弹出后，光标及当前编辑内容可见，文字对象坐标保持原值。
- 撤销框尺寸变化和保存重开后，正文、框尺寸、模式与排版资料正确恢复。

## M06.04 网址操作与共享文字编辑

**详细功能描述：**识别正文中可打开的网址，区分文字选中编辑与明确打开链接的操作。打开前使用系统标准入口处理地址；地址无效或打开失败时明确提示，不改变原文。

向 M02、M03、M08 等模块提供可复用的输入、选择、组合提交和样式编辑交互。宿主模块提供字段内容、允许的格式、提交与取消规则；M06 返回编辑结果。自由箭头标签仍属于自由箭头，关系标签仍属于对应关系，图片备注仍属于图片。

标签、名称与备注修改后由所属模块发出统一变化，M05 接收正式资料。移动箭头、图片或关系时，跟随位置由对应模块计算；共享编辑器只负责编辑交互。

**验收条件：**

- 正文中的网址能够通过明确操作打开，编辑或选择链接文字不意外跳转。
- 无效地址和系统打开失败提供真实结果，文字内容保持完整。
- 自由箭头标签、关系标签和图片备注能使用相同中文编辑行为，同时保留正确对象归属。
- 宿主字段的取消、撤销、复制、删除和重开不产生额外独立文字框或重复数据。
- 共享文字编辑提交后，宿主对象的检索资料按真实内容更新。

## M06.05 字体兼容与跨端文字保留

**详细功能描述：**项目保留原字体选择、字号、正文、文字框尺寸及排版模式。目标设备缺少指定字体时，明确展示替代字体提示，保留原字体设定和原文，并使用记录清楚的显示方式继续查看。

字体替代可能改变换行和视觉尺寸，显示与编辑必须区分原设置和当前可用字体，不能因打开或导出而静默改写文本。字体授权、是否允许随项目分发以及跨端可用性在技术与项目格式约定中处理，不默认打包未授权字体。

字体和排版数据通过 M09 保存与导出；M06 提供统一文字绘制或布局资料，确保画板、导出预览与最终输出使用一致文字内容。

**验收条件：**

- Windows 创建含中文和英文的文字项目，在 Android 修改并传回后，正文和设定正确保留。
- 缺字体设备明确显示替代情况，重回原字体可用设备后仍可恢复原设定。
- 打开、关闭、搜索和导出操作不会为适应当前字体擅自改写正文或显式换行。
- 项目显示、选区命中和导出文字使用对应的有效排版结果，差异有真实设备记录。

## 模块完整验收

在 Windows 和 Android 创建包含长中文、英文、网址、便签及不同样式的真实文字对象，完成输入、移动、缩放、改宽、复制、撤销、保存、跨端往返、搜索和导出。同步验证自由箭头标签、关系标签与图片备注使用共享编辑交互后归属正确。

M06.01 至 M06.05 的验收全部通过，并取得实际中文输入法、Android 键盘及跨端字体证据后，本模块才记为完成。输入法或设备缺少实测的条目维持未完成状态。
