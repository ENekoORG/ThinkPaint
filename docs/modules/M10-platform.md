# M10 界面与设备适配

计划分支：`module/platform`。需求来源：原 F17，以及 F01、F03、F05、F12 中的设备与生命周期适配。细分需求编号：M10.01 至 M10.06。

本模块负责应用外壳、工具面板、标准输入事件、快捷键路由、主题外观和设备适配，为各功能模块提供一致的双端使用环境。

## 职责边界与协作接口

M10 提供页面容器、工具和面板注册、焦点与快捷键上下文、标准笔鼠触控事件、设备能力、系统键盘和应用生命周期通知。管理主页的内容和画板目录属于 M01，画板视图与导航属于 M04，M10 负责承载与平台连接。

输入事件保留设备类型、指针身份、位置、时间、压力和可用按键等实际资料。M02 使用这些事件计算笔迹、压力响应、平滑和擦除；M04 处理坐标转换、平移缩放和边缘移动；M06 处理中文组合输入与文本编辑。输入路由由共享交互状态确定归属，不能使同一动作同时触发互相冲突的工具。

M09 处理项目保存和恢复，M10 报告前后台、窗口、系统取消和设备状态，调用约定入口并展示真实结果。M03、M06、M08 等模块维护各自对象的内容与样式，M10 提供统一主题和装饰设置。共享规则见[模块协作约定](../MODULE_CONTRACTS.md)，需求总览见[项目需求](../REQUIREMENTS.md)，依赖和分支安排见[开发计划](../DEVELOPMENT_PLAN.md)。

## M10.01 应用外壳与工具面板

**详细功能描述：**提供主页、编辑页、设置和必要状态提示的应用外壳，承载 M01 主页与各编辑模块工具。画笔、图片、文字、关系、搜索和对象属性通过明确扩展入口加入工具栏及面板，工具可用状态来自对应模块。

Windows 支持适合键鼠与触控板的窗口布局，Android 支持适合手指点击的工具区域与系统安全显示区域。窗口大小或方向变化时调整面板，不覆盖正在编辑的必要区域。当前工具、当前画板、保存状态和筛选状态可辨认。

面板打开、关闭和切换遵循一致焦点规则，错误提示与正在执行的操作对应。工具按钮不能以模拟完成状态替代真实模块结果。

**验收条件：**

- M01 主页和各模块工具可在双端实际外壳中使用，导航后当前画板及工具状态正确。
- 改变窗口大小、Android 屏幕方向及面板状态，必要操作可访问，正在编辑内容可见。
- 工具不可用、执行中、失败和完成状态来自真实模块反馈。
- 面板切换不误结束输入、不重复执行编辑，也不遗留错误焦点。

## M10.02 标准笔、鼠标与触控输入

**详细功能描述：**将鼠标、触控板、手指、主动笔和数位板的系统输入转为共享事件，保留指针身份、动作阶段、位置、时间、可用压力、按键及取消信息。没有压力能力的设备明确报告能力范围，鼠标绘画由 M02 使用固定笔宽。

区分笔与触摸来源，并处理笔靠近、手掌触碰、多个触点、设备中断和系统取消。防误触根据系统与设备可提供的资料工作，支持范围以实际硬件验证为准。

压力响应曲线、轨迹采样、平滑、箭头生成和橡皮算法由 M02 实现；平移缩放手势由 M04 实现；M10 保证事件完整并路由到当时拥有该操作的模块。

**验收条件：**

- 实测键鼠、触控板、Android 触屏、主动笔及 Windows 数位板或笔屏的动作阶段与取消事件正确。
- 指针离开窗口、系统打断、失去焦点或设备断开后，不遗留持续绘画或拖动状态。
- 能力存在时压力与按键资料可传给 M02；缺少能力时明确显示实际支持范围。
- 笔书写与手指移动画板按设置分别生效，不因同一次输入产生额外笔迹或错误缩放。

## M10.03 快捷键、焦点与输入优先级

**详细功能描述：**提供可调整快捷键、工具切换和焦点上下文。文本编辑及输入法、对话框与菜单、当前工具、画板导航分别声明能接收的操作；按照共享优先级路由，同一按键不重复触发冲突动作。

Windows 支持常见键盘、鼠标修饰键与触控板操作，Android 支持外接键盘和可用笔按键。快捷键调整显示冲突，保留恢复默认操作；设备不具备的按键或手势不显示为可正常使用。

M06 编辑中文时，字母、空格、方向、删除和确认等输入由文本与输入法处理。M02 和 M04 需要的临时修饰操作通过共享状态接入，工具完成或取消后正确释放。

**验收条件：**

- 画板、文字输入、菜单和对话框中，同一按键仅触发当前规定的行为。
- 修改快捷键、发生冲突及恢复默认均有明确结果，重启后设置正确保留。
- 外接键盘和可用笔按键的映射在实际设备上生效。
- 修饰键按下期间失去焦点或取消操作后，不出现卡住的临时工具状态。

## M10.04 主题、背景与装饰

**详细功能描述：**提供纯色、点阵、方格和软木板等画板背景，以及便签、照片边框、图钉和线绳等装饰外观。装饰可以关闭，各对象仍按真实边界、归属和连接关系编辑。

主题提供统一颜色和界面可读性设置；背景由 M04 绘制，对象装饰由对象所属模块使用共享外观资料显示。便签正文与样式属于 M06，图片内容与边框属于 M03，线条几何与样式属于 M02，关系绑定与资料属于 M08，M10 负责选择入口及主题协调。

导出时由 M09 采用已明确选择的背景和装饰规则，预览与结果一致。切换外观只改变规定的显示设置，保留正文、原图、坐标和真实关系。

**验收条件：**

- 所提供背景和装饰能切换、关闭、保存重开，并在双端正确读取。
- 主题变化后文字、选区、工具和关系线保持可辨认。
- 外观切换不改变对象坐标、命中规则、归属和端点绑定。
- 背景及装饰参与导出时，与 M09 的选项和预览一致。

## M10.05 操作偏好与设备能力设置

**详细功能描述：**集中管理工具栏布局、快捷键、触摸绘画、笔按键及其他设备操作偏好，并明确区分应用设置、设备设置和可携带的画板显示设置。

Android 默认使用笔书写、手指平移和双指缩放，允许明确开启手指绘画。Windows 提供鼠标、键盘、触控板及可用数位板设置。M02 维护画笔和压力响应参数，M04 维护视图操作参数，M10 汇集入口并按约定保存偏好。

设置展示实际能力，不把系统或硬件缺失的压力、橡皮端、笔按键和防误触列为已支持。设备更换或权限变化后更新能力状态，保留可恢复的原有偏好并说明当前是否生效。

**验收条件：**

- 偏好在重启后生效，各模块读取同一有效设置，不产生互相矛盾的行为。
- 手指绘画开关与默认笔触分工在实际 Android 设备上正确工作。
- 不同设备能力和断开重连状态有准确展示，未支持能力不会虚报成功。
- 项目跨端传递保留可携带显示设置，不把上一设备特有的按键映射强加到新设备。

## M10.06 双端生命周期与实机适配

**详细功能描述：**处理窗口焦点、最小化、前后台切换、Android 系统返回、屏幕方向变化、应用进程回收和系统取消输入。对仍在进行的绘画、拖动、文字编辑和项目操作，通知拥有该状态的模块按共享规则完成、取消或阻止离开。

应用进入后台或请求关闭时通知 M09 执行规定的保存流程，并显示实际保存状态。异常退出后的项目恢复由 M09 处理，M10 提供恢复入口和结果展示，不能承诺系统强制终止时尚未发生的保存已成功。

双端验证记录真实设备、系统与驱动版本、输入方式、操作步骤和结果。压感、防误触、中文输入与后台恢复等验收分别记录，性能目标在工程装配的验证约定中预先固定。

**验收条件：**

- 实际 Windows 和 Android 环境切换前后台、改变方向、取消输入后，工具和焦点状态正确。
- 生命周期变化通知 M02、M04、M06、M09，实际保存、恢复与编辑结果和界面状态一致。
- 应用正常关闭、异常退出及 Android 进程回收分别验证，恢复来源和未保存范围符合正式验证目标。
- 记录必要硬件能力证据，缺设备或未实测的能力保持未完成状态。
- 已选技术路线对应的双端构建和启动步骤可复现，验证对象使用实际应用。

## 模块完整验收

使用实际 Windows 键鼠、数位板或笔屏、Android 触屏与主动笔，在真实编辑场景完成工具切换、绘画、平移缩放、中文输入、搜索、设置保存和前后台切换。核对事件归属、快捷键优先级、装饰显示及保存恢复结果。

M10.01 至 M10.06 的验收全部通过，且与各模块协作有真实双端证据后，本模块才记为完成。技术路线、具体框架和构建目录通过开发计划中的工程装配与接口准备统一确定。
