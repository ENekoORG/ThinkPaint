# M02 绘图

本模块负责手绘笔迹、鼠标绘图、轨迹平滑、擦除和自由箭头。模块分支为 `module/drawing`。需求来源为 F01、F04，并参与 F10、F17。

需求总览见 [项目需求](../REQUIREMENTS.md)，共享约定见 [模块协作协议](../MODULE_CONTRACTS.md)，任务安排见 [开发计划](../DEVELOPMENT_PLAN.md)。

## 职责边界

绘图模块决定轨迹如何形成笔迹或线形，如何响应压力，如何平滑、擦除和编辑路径。笔迹保留为可编辑数据，颜色、压力、粗细与路径共同参与保存和恢复。

自由箭头与关系连线使用统一线对象。M02 负责路径、控制点、线形及箭头外观；M08 负责端点绑定、目标改接和关系查询。绑定或解除绑定时保留线对象标识、路径、文字及样式，不建立另一套不可互换的箭头数据。

对象标识、归属、通用选择变换和编辑事务由 M07 提供；坐标转换与绘制调度由 M04 提供；原始设备事件和设备能力由 M10 提供。图片附着关系由 M03 发起并通过 M07 修改，绘图模块提供附着的笔迹或箭头内容。

## 提供接口与协作模块

- 向 M04 提供笔迹与线形的绘制、边界和命中适配，支持画板坐标及图片局部坐标中的内容。
- 向 M07 提供创建、修改、局部擦除及取消操作所需的编辑数据，以完整事务提交；通用对象变换使用 M07 的规则。
- 向 M08 提供自由箭头路径、端点、控制点和线形更新能力；读取 M08 提供的端点绑定信息，显示可区分的绑定状态。
- 从 M10 接收标准化鼠标、触控笔与数位板事件；从 M04 获取坐标转换、当前视图和活动绘制位置。
- 向 M09 提供带版本的笔迹和线形数据编解码、资源引用与导出绘制适配；画笔设置通过统一设置服务保存。
- 与 M06 协作编辑箭头文字，与 M03 协作处理图片上的附着笔迹。笔迹名称、备注和标签采用 M08 的公共资料定义，并通过统一对象变更供 M05 更新检索。

## M02.01 全色画笔与常用预设

来源：F01。

提供普通笔、荧光笔，以及用于擦除的工具入口。支持连续调整笔宽、颜色和不透明度，提供取色界面及 RGB/HEX 颜色输入，支持自定义颜色、吸色、最近使用颜色及常用画笔预设。显示和导出遵守统一颜色约定，工具切换后明确显示当前颜色、笔宽和模式。

画笔设置、最近颜色与预设可以在重开应用后恢复。对象创建后仍可改色、调整粗细及不透明度，修改不破坏其路径和归属。选中已有笔迹修改样式与设置下一笔样式应有清晰的操作对象。

可验收条件：

- 两端可创建普通和荧光笔迹，连续调整笔宽、颜色与透明度，重开后保留设置与预设。
- 吸色取得当前显示内容的颜色，最近颜色列表随使用更新；预设可再次应用。
- 已有笔迹的样式可修改、撤销和重做；保存重开及导出后保留路径与样式。

## M02.02 压感触控笔与数位板绘图

来源：F01、F17。

在 M10 提供的设备能力范围内，接收笔尖位置、压力、侧键、橡皮端及输入取消事件。支持压力改变笔宽，并调整压力响应；关闭压感后使用固定笔宽。笔侧键和橡皮端动作可以配置，设备不支持的能力在设置中明确显示。

笔画从按下到抬起构成一次编辑；切换工具、失去输入、系统取消或应用进入后台时，应按共享输入规则结束或取消本次笔画，释放输入占用。笔迹不能延伸到下一次无关输入。防误触由 M10 采集与分发，绘图模块遵守当前笔与手指的工具分配。

可验收条件：

- 在实测 Windows 数位板或笔屏、Android 主动笔上，力度变化产生可控笔宽变化，关闭压感后保持固定笔宽。
- 压力响应调整生效，侧键与橡皮端动作符合已配置行为；设备型号、系统及驱动记录完整。
- 抬笔、工具切换、系统取消和前后台切换后不残留持续绘画状态；完成笔画可一次撤销。
- 所需设备未实测时，本条相应硬件验收保留未完成状态。

## M02.03 鼠标自由绘图与笔迹编辑

来源：F01、F04。

使用鼠标在画板任意位置绘制固定笔宽的自由笔迹，并提供连续实时预览。绘制过程中使用 M04 的坐标转换，使缩放前后的落笔位置与指针一致；画板正负坐标和远距离区域使用同一行为。

完成后的笔迹作为独立对象接入 M07 的选择、移动、缩放、旋转、复制、删除和层次管理。修改笔迹样式时保留路径的可编辑性。处于文字组合输入或其他占用输入的状态时，鼠标操作遵守共享输入分发规则。

可验收条件：

- 鼠标可连续绘制、抬起结束和取消笔画，预览与最终笔迹位置一致。
- 缩放与远坐标下，笔迹创建和命中准确；混合选择图片、文字和笔迹后可共同变换。
- 复制、删除、撤销及保存重开保留笔迹内容、样式和归属；鼠标输入保持固定笔宽。

## M02.04 可调轨迹平滑

来源：F01、F04。

为手绘与自由箭头提供可关闭、可调强度的轨迹平滑。实时预览和最终路径采用一致规则，保留有意绘制的主要转折与准确终点。短笔画、快速转弯、速度变化和输入取消均应有稳定结果。

平滑增加的输入延迟与路径变化需要在实测设备上记录，按共享质量规范中的场景和目标验收。平滑强度与设备输入类型可保存为设置，关闭平滑后保持原始绘制意图。

可验收条件：

- 同一组测试轨迹在关闭、较轻和较强平滑下可检查差异，轻微抖动得到减少，主要转折和终点保留。
- 短距离、快速折返、抬笔与取消输入不出现延长线、路径跳变或异常控制点。
- 在目标设备上记录平滑强度、输入延迟及可核对的测试轨迹，并满足共享质量目标。

## M02.05 整笔与局部擦除

来源：F01。

整笔擦除删除命中的完整笔迹；局部擦除只移除擦过的路径部分，剩余部分保留原有颜色、粗细、压力信息、可编辑性及归属。局部擦除产生的路径片段通过 M07 的事务和标识规则登记，撤销后恢复原始完整笔迹。

橡皮擦只作用于当前允许擦除的目标，不损伤下面的图片、文字或无关连线。图片附着笔迹的擦除采用相应局部坐标。一次连续擦除构成一个可理解的撤销步骤，取消操作不留下部分改动。

可验收条件：

- 整笔擦除和局部擦除可清楚区分，擦除后图片与其他对象完整。
- 多段及压感笔迹被局部擦除后仍能选择、编辑、保存和再次擦除。
- 一次连续擦除可整体撤销、重做；附着于图片的笔迹在图片变换后仍准确擦除。
- 保存重开保留剩余路径与归属，撤销不遗留重复片段或悬空对象引用。

## M02.06 自由箭头与可编辑线形

来源：F04、F09。

沿鼠标或笔轨迹创建直线、折线或自由曲线，并按终点方向形成箭头。提供单向、双向及无箭头线形，支持颜色、粗细、虚实、箭头大小，完成后可编辑端点和控制点。Windows 通过修饰键临时约束水平、垂直或共享约定中的固定角度。

线对象可添加简短文字；文本输入复用 M06，线条与文字的归属和布局按共同线对象协议处理。自由箭头默认保持画板路径，绑定由明确操作或可见吸附确认建立，轨迹平滑不能自动建立绑定。

与 M08 协作支持自由箭头绑定对象、解除绑定、指定端点改接和随对象更新线形。以上状态之间转换保留稳定标识、关系文字、资料和外观，选中时可查看端点的实际归属。

可验收条件：

- 三类路径、单双向箭头及无箭头线形可创建、修改、撤销和保存；修饰键约束方向正确。
- 平滑后的自由箭头可以再次调整端点和形状，文字内容与样式在双端往返后保留。
- 自由路径、单端绑定和双端绑定状态可区分；绑定转换保持原对象标识及文字资料。
- 平滑、拖动或普通视觉重叠不会静默绑定对象；取消绘制或编辑不留下半成品。

## 模块完整验收

使用同一验收项目覆盖鼠标、Windows 数位板或笔屏、Android 触屏与主动笔，在正负坐标及远距离区域创建笔迹和自由箭头，完成选择、样式编辑、缩放旋转、平滑、两类擦除及绑定转换。所有编辑接入 M07 的事务和撤销，图片上的批注跟随图片变换；关闭重开、双端传递与导出后保留路径、压力、样式、文字和对象关系。

交付记录包含测试设备、系统和驱动、平滑设置、输入延迟、已通过条目及未验证能力。只有六项条目及相关联合验收全部通过后，模块才记为完整完成。
