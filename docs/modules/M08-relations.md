# M08 线索与关系

本模块负责对象之间的关系、端点绑定与维护、来源备注、标签状态和关系专注。模块分支为 `module/relations`。需求来源为 F09、F15、F16，并参与 F04、F07、F11。

需求总览见 [项目需求](../REQUIREMENTS.md)，共享约定见 [模块协作协议](../MODULE_CONTRACTS.md)，任务安排见 [开发计划](../DEVELOPMENT_PLAN.md)。

## 代码目录与独立设计

统一采用 Flutter + Dart。计划代码目录为 `packages/thinkpaint_relations/`，公开入口为 `lib/thinkpaint_relations.dart`，私有实现放在 `lib/src/`，本模块验证放在 `test/`。这些代码目录在后续工程任务中建立。

本模块独立设计自己的页面、面板、对话框、工具与局部状态，设计资料按需要放在 `docs/design/M08/`。M10 统一主题、外壳、导航与焦点；模块通过页面、面板、工具和设置贡献接入，具体布局和交互由本模块细化并审阅。

静态依赖只使用两个共享协议包和本模块依赖，功能包之间不互相 import。提供：RelationsPort、MetadataPort、纯 EditRule、关系与资料界面贡献。消费：DocumentReadPort、EditorPort、LineGeometryPort、ViewportPort、TextEditingFactory。

依据：[技术决定](../architecture/PLATFORM_DECISION.md)、[工程结构](../architecture/PROJECT_STRUCTURE.md)、[共享接口](../architecture/SHARED_CONTRACTS.md)、[模块依赖](../architecture/MODULE_DEPENDENCIES.md)、[独立界面设计](../architecture/UI_DESIGN_GUIDE.md)。

## 职责边界

关系模块决定一条线连接哪个对象、端点如何跟随目标、对象变化时哪些关系受影响，以及如何查看和筛选关联资料。对象名称、来源、备注、日期、标签和状态采用统一资料结构，本模块提供资料编辑与关系查询行为。

自由箭头与关系连线采用同一线对象约定。路径、控制点和线形能力由 M02 提供，绑定信息与关系行为由 M08 提供，文字编辑由 M06 提供。绑定转换保留对象身份和已有内容。对象标识、通用变换、归属与撤销事务由 M07 提供，关系端点不另建一套对象身份系统。

图片档案盒的实际收纳由 M03 发起，关系模块只计算并提供端点变更预览及执行数据。关系专注的邻居与范围由本模块计算；搜索和筛选入口由 M05 提供，画板高亮、淡化与定位由 M04 按显示状态呈现。

## 提供接口与协作模块

- 向内容模块提供可连接目标、连接点、端点绑定状态和对象关联查询；目标坐标由 M04、M07 的变换协议计算。
- 向 M02 提供线对象绑定、解绑与端点改接行为，复用其路径和线形编辑能力；向 M06 请求关系文字编辑。
- 向 M03 提供收纳涉及的关系清单、改接预览和操作数据，与图片归属变化合并为 M07 的一次事务。
- 向 M07 提供删除、复制、变换、分组和撤销时的关系维护数据，校验目标有效性，防止悬空引用。
- 向 M05 提供名称、关系文字、来源、备注、标签、状态及邻接查询，向 M04 提供专注对象集合和显示强调状态。
- 向 M09 提供关系绑定扩展的带版本编解码，公共资料随 M07 的统一对象结构保存，并与 M09 联合验证双端往返；通过统一变更通知更新检索和专注视图。

## M08.01 连接创建与端点绑定

来源：F09、F04。

从图片、文字框、分组或档案盒的连接点创建关系线，也可将已有自由箭头的指定端点绑定到对象。提供直线、曲线、方向、颜色、虚实和关系文字，路径及线形复用 M02，文字编辑复用 M06。

绑定必须由连接操作或可见吸附确认建立，普通重叠和平滑轨迹不隐式改动关系。支持解除绑定和明确重接某个端点；选中线时显示实际端点目标，自由路径、单端绑定和双端绑定可区分。解除绑定时保留端点当前画板位置。

可验收条件：

- 各规定对象类型可连接，创建或重接时可以检查实际目标和吸附状态。
- 自由箭头转换为绑定线、单端解绑和指定端点重接后，其他端点及对象标识、文字和样式保留。
- 解除绑定后端点位置不跳动，后续移动原目标不再带动该端点。
- 创建、编辑和绑定可取消、撤销、重做并保存；文字组合输入遵守 M06 的输入规则。

## M08.02 端点随动、关系维护与回环

来源：F09、F07、F08。

目标移动、缩放、旋转、分组或解组时，按稳定目标标识更新端点和线形。隐藏或筛选只改变显示，真实绑定保留。删除目标时一起移除关联连接，撤销后恢复目标和连接；复制包含内部关系的对象集合时，内部端点重建到副本目标，原对象关系不受影响。

支持两端指向同一对象的回环，仍能选择线条、编辑端点、文字和样式。图片收纳时向 M03 提供逐条端点改接计划；确认后保留未受影响端点和全部线资料，与图片收纳一次提交。同盒双端形成回环，不自动合并或删除；图片拖出后保留指向档案盒的实际连接。

档案盒解散或连同内容删除前，提供当前连接及目标移除的影响，供 M03 预览。需要保留的关系可先明确重接；执行移除后不保留悬空引用。两端距离很远时，支持向 M04 请求定位另一目标。

可验收条件：

- 目标变换及分组解组后端点准确跟随，隐藏和筛选不改变绑定。
- 删除与撤销恢复关系；复制混合对象集合后内部连接正确指向副本，没有悬空目标。
- 同对象回环可以选中、编辑并保存，多个回环保持独立标识和资料。
- 档案盒改接先预览再确认；取消无变化，撤销和重做与收纳整体恢复，拖出不自动重接。
- 档案盒两种移除行为均可预览影响、明确重接或随目标移除，并整体撤销恢复。
- 远距离目标可定位，双端保存往返后端点目标一致。

## M08.03 线索标题、来源与备注

来源：F15。

为图片、文字、笔迹、箭头、关系线、分组、区域和档案盒提供统一的标题、来源网址、说明与日期资料。图片导入保留文件名，来源可以补充或修改，网址可打开。资料面板明确显示当前编辑对象，并可从对象列表、图片查看或关系选中状态进入。

资料附着于稳定对象标识；对象改名、变换、裁剪、收纳和显示筛选不丢失资料。复制按通用对象规则保留资料并创建独立副本，删除和撤销一并处理。日期保留其原有含义与输入值，不用文件修改时间静默覆盖。

可验收条件：

- 各规定对象和关系线可编辑标题、来源、说明及日期，并明确对应对象。
- 导入文件名可核对，修改来源与日期可以撤销，网址可以通过平台入口打开。
- 改名、裁剪、收纳、复制和重开后资料正确，副本资料修改不影响原对象。
- 双端传递保留全部资料字段，资料变更后搜索结果更新。

## M08.04 自定义标签与核实状态

来源：F15、F16。

对象和关系线可添加多个自定义标签，并设置待核实、已核实、已排除等预置状态，支持自定义状态。状态由使用者明确设置，软件不根据连线或邻居状态自动推断事实。标签与状态编辑支持选中对象集合，作为一次完整事务修改。

向 M05 提供按标签和状态检索、筛选所需数据，向专注查看提供当前匹配集合。修改标签、状态以及撤销、复制和删除时，检索与显示结果同步更新。资料归属于对象数据，显示过滤不移除标签或状态。

可验收条件：

- 预置和自定义状态、多个标签可设置、修改、移除并保存，自定义内容双端一致。
- 批量设置范围明确，取消不改动，确认后可整体撤销和重做。
- 搜索或筛选可找到对应对象及关系，修改或撤销后结果及时更新。
- 建立或移除关系不会自动改变核实状态；复制后标签状态保留且可独立编辑。

## M08.05 关系专注与逐层查看

来源：F16、F11。

选中对象后，计算其直接关联对象和连线，由画布突出相关内容并淡化其他内容。支持继续查看下一层关系、隐藏全部连线、仅显示选中对象相关连线，以及恢复完整画板。可通过 M05 的标签、状态和颜色筛选限定查看范围。

专注和筛选是查看状态，不修改对象内容、布局或实际绑定，界面持续显示当前范围。更新关系或资料后重新计算显示集合，不保留错误高亮。循环关系和回环查询不得无限展开或重复生成对象。

搜索结果被专注或筛选隐藏时，结果显示其状态，经过明确操作再临时显示并定位；折叠档案盒由 M03 打开。专注状态下新增对象与工具选择遵守共享显示规则，不产生创建后无法找到的内容。导出预览由 M09 明确选择当前筛选结果或完整内容。

可验收条件：

- 直接关系、逐层查看和回环场景返回正确集合，可恢复完整画板而不改变坐标、数据和绑定。
- 全部隐藏、仅相关线及标签状态颜色筛选范围可识别，修改关系、标签或状态后显示更新。
- 搜索折叠、隐藏或被筛选对象时可检查状态并通过明确操作定位，不静默改写对象隐藏属性。
- 专注下创建内容可继续找到和编辑，选择和快捷键行为符合当前工具规则。
- 导出预览明确展示当前范围或完整内容，实际导出与预览一致。

## 模块完整验收

使用图片、文字、分组、档案盒与自由箭头建立混合关系项目，覆盖自由与绑定状态转换、移动缩放旋转、删除与恢复、内部关系复制、同对象回环、图片收纳改接和档案盒移除。线对象身份、路径、文字、资料与端点在所有转换和双端往返中保持正确。

资料编辑、标签状态、搜索筛选和专注查看共同验收，确认查看行为不改变真实数据。交付包含连接前后目标清单、事务撤销结果、搜索与专注结果、跨端项目检查和未通过项。只有五项条目及联合验收全部通过后，模块才记为完整完成。
