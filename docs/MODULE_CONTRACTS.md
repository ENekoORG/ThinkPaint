# ThinkPaint 模块协作约定

更新日期：2026-10-18。模块划分见 [需求索引](REQUIREMENTS.md)，开发与分支见 [开发计划](DEVELOPMENT_PLAN.md)。

十个模块分别拥有业务实现、界面和测试，通过统一对象、操作和资源接口协作。本文件规定职责与数据语义；选定技术路线后，由相应模块给出实际接口签名、代码路径和兼容版本，管理对话统一审查。

## 共享接口责任

| 接口 | 主责模块 | 参与方 | 需要固定的内容 |
| --- | --- | --- | --- |
| 对象注册与身份 | M07 | 全部内容模块 | 稳定标识、类型、变换、边界、层次、归属、锁定隐藏、扩展数据 |
| 专用内容适配 | 对应内容模块 | M04、M05、M07、M09 | 几何、命中、绘制、专用编辑、数据版本、搜索资料 |
| 编辑事务与通知 | M07 | 全部编辑模块、M05、M09 | 预览确认取消、校验、执行、撤销重做、一致快照和事务通知 |
| 坐标与视图 | M04 | M01、M02、M03、M05、M06、M07、M08 | 屏幕画板局部坐标、视野、定位、导航历史、临时查看条件 |
| 输入与工具生命周期 | M10 | M02、M03、M04、M06、M07、M08 | 标准设备事件、工具注册、唯一会话、取消、输入法优先级 |
| 线条几何与对象绑定 | M02、M08 分别负责 | M03、M04、M07 | 路径与样式、端点归属、随动、回环、资料和对象身份保留 |
| 容器与批注归属 | M07 | M03、M04、M08 | 分组区域盒和图片批注的关系、变换、收纳改接和删除恢复 |
| 项目资源与格式 | M09 | 各内容模块、M01、M07 | 原图引用、版本化编解码、一致写入、迁移、错误与恢复 |
| 搜索与资料变动 | M05 | M01、M03、M06、M07、M08、M09 | 搜索资料、查询条件、索引更新、结果定位路径和临时显示 |
| 元数据与关系专注 | M08 | M05、M07、M04 | 来源备注标签状态、邻接查询、专注结果与查看语义 |

## 对象和内容适配

M07 维护对象公共状态。内容模块分别拥有笔迹与自由路径、图片与档案盒、文字、关系扩展及区域等专用数据。公共元数据结构由 M07 和 M08 共同确定，使用一个定义并随 M07 的公共对象状态保存。各模块的图片备注、标题和来源等入口编辑对应公共字段，不另存一份私有副本。

内容注册至少包含类型和数据版本、边界与命中、绘制与导出呈现、专用修改、编解码和可检索资料。M04 只调度显示和坐标，M05 只建立可重建索引，M09 只组合和保存项目，不复制这些类型的编辑逻辑。

图片批注、分组、区域和盒的移动归属使用同一套规则。对象不能产生归属循环；关系回环属于连接语义，与归属循环分别处理。新增容器不得自行维护另一套父子关系。

## 事务和保存一致性

操作先形成变更计划，校验全部参与方后，由 M07 一次执行。预览不改变正式数据；取消不提交；失败不留下部分内容。撤销重做覆盖资源引用、对象归属、几何、资料和关系。

M05 和 M09 消费完整事务后的通知或一致快照。保存中途失败保留最近有效项目；搜索索引可从项目重建，不能成为内容的唯一保存位置。

当前会话的撤销栈归 M07，备份恢复归 M09，导航返回归 M04。对象隐藏、临时显示、筛选与专注状态分别表示，查询展示不静默改变对象的真实隐藏属性。

## 输入和工具调用

M10 从实际设备采集并标准化事件，报告指针、压力、按钮、设备能力和取消状态。M04 转换坐标并处理画布导航，当前工具由所属模块处理专用操作。工具会话有唯一持有者，明确开始、更新、结束和取消。

笔迹和压感响应由 M02 实现，图片裁剪由 M03 实现，通用选择变换由 M07 实现，绑定连线由 M08 实现。中文组合输入由 M06 管理，优先于全局快捷键；M10 提供焦点、键盘和窗口变化信息。

前后台、窗口焦点丢失或系统取消事件使各工具正确结束或取消，并通知 M09 处理保存。不同设备的动作不应被重复解释成笔迹与导航。

## 自由箭头和关系线

M02 维护路径几何、平滑和箭头样式，M08 维护可选的对象绑定、端点随动、重接与邻接查询。两者采用同一线对象身份与资料约定。绑定或解除绑定保留对象标识、文字和样式。

关系端点更新通过约定的几何接口执行，不直接改写另一模块私有字段。M08 计算回环和绑定布局，调用线条几何能力呈现；M06 提供文字编辑，标签归属和位置由当前线工具维护。

## 档案盒收纳联合操作

1. M03 收集图片及附着内容，检查是否允许加入目标盒。
2. M08 查询受影响关系，生成端点改接和回环计划。
3. M03 呈现联合预览，明确确认或取消。
4. M07 校验并一次提交图片归属与连接变更，通知 M04、M05 和 M09。
5. 一次撤销恢复全部图片归属、端点、文字和样式；重做恢复收纳后的状态。

图片拖出后，已经改接的连接仍指向盒。解散或删除预览受影响连接，移除目标连接与恢复遵守同一事务规则。批注内容由 M02、M06 提供，M03 负责附着意图和裁剪显示，M07 负责归属与通用变换。

## 搜索定位和关系专注

内容模块提供名称、文字、备注和标签等真实资料，M05 建立索引并返回对象标识、所属画板及容器定位路径。M01 打开画板，M03 展开档案盒，M07 查询隐藏锁定状态，M04 定位高亮。

M08 提供关系邻居和逐层专注结果；M05 提供资料筛选条件。M04 应用临时查看条件而不改写布局。M09 导出在预览中明确选择当前条件或完整内容。

## 接口变更和实际对接

接口在模块开发前记录负责人、版本、实际路径、输入输出、失败处理和验证样例。需要改动时先列出受影响模块和兼容方式，由管理对话安排主责模块修改，再更新调用方。

模块可独立交付私有能力和类型适配，联合操作通过真实对接验收。未实现的接口或缺少设备时，记录待集成或待验证；空实现和模拟结果不能作为整项功能完成证据。
