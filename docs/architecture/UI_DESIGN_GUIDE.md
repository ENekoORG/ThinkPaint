# ThinkPaint 模块独立界面设计约定

更新日期：2026-10-19。技术路线为 Flutter + Dart，界面接入协议见 [共享接口](SHARED_CONTRACTS.md)。

每个模块独立细化自己的功能、页面、面板、对话框、工具交互和状态。整体规划统一公共约定，模块对话组织本模块调研、方案审阅和设计记录。

## 模块设计范围

| 模块 | 主要设计对象 |
| --- | --- |
| M01 | 画板主页、分类收藏、卡片列表、项目操作与主页设置入口 |
| M02 | 画笔工具、压感平滑设置、橡皮与箭头交互、活动笔迹反馈 |
| M03 | 图片添加与裁剪、单图查看、档案盒展开折叠、收纳及改接预览、图片批注 |
| M04 | 画布导航、缩放提示、小地图、位置收藏、边缘平移和查看反馈 |
| M05 | 搜索入口、查询筛选、结果列表、目标定位与特殊状态提示 |
| M06 | 文字输入状态、字体样式、便签、文字框布局、共享编辑交互 |
| M07 | 选区与控制柄、对象列表、层次分组、区域排版、撤销操作反馈 |
| M08 | 连接点与端点、关系文字、来源备注、标签状态与关系专注 |
| M09 | 保存状态、恢复入口、项目导入结果、导出预览与分页操作 |
| M10 | 应用外壳、公共导航、设置容器、主题、焦点与设备操作偏好 |

设计以实际承载界面为范围，可以是一张页面、一个面板或工具覆盖层。底层能力补充状态、错误和交互说明即可。

## 设计资料目录

各模块按需要使用 `docs/design/M01/` 至 `docs/design/M10/`，推荐资料名称如下：

- `DESIGN.md`：目标、场景、方案、已采用的选择和理由。
- `FLOWS.md`：操作流程、状态、提交取消、失败与恢复。
- `REVIEW.md`：方案审阅、具体修改和决定记录。
- `assets/`：必要的视觉稿、线框图或参考材料；来源、用途与版本写清楚。

这些是后续按需要建立的目录和文件。任务卡链接实际设计资料，并保留对应需求编号、接口版本与实现前置。

## 独立设计流程

1. 阅读本模块需求、共享协议和相关联合场景，识别本轮要解决的具体行为。
2. 查阅适合的官方产品资料或现有组件，对有实质分歧的方向给出二至三种方案、代价和推荐。
3. 为实际界面形成可审阅的流程、线框或视觉稿，在模块对话中审阅后记录采用方案。
4. 补齐编辑中、加载、空内容、失败、取消和恢复等实际状态，以及键鼠、笔和触控行为。
5. 检查接口、主题和跨模块流程，提出必要的变更请求，再按相应授权进入实现。

图片和原型用于审阅，准备状态与实际功能验证分别记录。设计审阅通过不替代设备、保存和联合操作验收。

## 公共视觉与平台约定

M10 提供主题角色、文字层级、间距、焦点与触控可操作性约定。模块引用公共主题，按其内容细化布局和信息层级；公共视觉角色的调整由 M10 协调。

首批视觉基线采用暖纸色、清晰文字对比和 Android 平板优先，保留窄屏、横竖屏、分屏及 Windows 窗口适配。具体颜色和尺寸在公共视觉方案审阅后记录，模块设计可提出所需角色。

M01 的侧栏底部依次为回收站和独立设置行，分类滚动时保持入口可见。M01 维护主页入口，M10 承载设置页；返回后恢复原有分类、排序和有效滚动位置。其他模块沿公共导航与返回规则接入自己的页面和面板。

## 界面扩展注册

PageContribution、PanelContribution、ToolContribution、SettingsContribution 定义在 Flutter 协议包。每项包含模块命名空间标识、标题与入口资料、构建工厂、所需服务以及焦点或生命周期约定。

模块标识使用 `M03.*` 等命名空间，M10 外壳接收注册项；应用装配层注入实际服务。模块内部页面和局部导航由模块管理，公共路由和导航结构由装配与 M10 统一登记。

工厂在挂载时构建 Widget，构造阶段只登记能力。模块的精细设计通常在自身包内完成；新增公共槽位或路由语义时，通过共享接口变更流程处理。

## 界面状态与业务真源

选择页签、展开面板和草稿输入等局部状态由模块维护，正式对象数据归 M07，项目持久化归 M09。搜索索引、缩略图和渲染缓存保持可重建，界面不能各自保存一套可独立改写的正文。

当前画板、保存版本、输入法状态和执行结果通过接口读取。跨模块预览明确确认后形成同一编辑；取消或失败时按实际结果呈现。可见的加载与错误状态不代表操作已完成。

## 协作边界

模块对话可以在自己的任务卡、设计目录和本模块需求中细化已有功能，保留原细项编号与验收条件。减少需求、扩大产品范围、修改其他模块或公共协议时，先由管理对话协调。

同一模块已在其他 worktree 设计或实现时，新的公共规划在管理仓库提供补充；同步由对应负责人按实际基线处理，保留已有改动和审阅记录。
