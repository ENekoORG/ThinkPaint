# ThinkPaint 功能分类与项目需求

文档版本：0.3。更新日期：2026-10-19。

ThinkPaint 面向 Android 和 Windows，在可向四个方向持续扩展的画板上组织图片、文字、手绘和关系连线。需求按十个功能块组织，每个类别由独立开发对话负责，类别内部以细项领取和验收。

## 统一技术与模块设计

统一技术路线为 Flutter + Dart + 自定义绘制画布。十模块分别拥有自己的代码包、界面与功能设计，通过共享协议协作。具体目录和接口以 [工程结构](architecture/PROJECT_STRUCTURE.md)、[共享接口](architecture/SHARED_CONTRACTS.md)和[模块依赖](architecture/MODULE_DEPENDENCIES.md)为依据。

各模块可以在自己的 `docs/design/Mxx/` 细化流程、原型与视觉稿，M10 统一主题、导航、焦点和外壳。设计方式见 [界面设计约定](architecture/UI_DESIGN_GUIDE.md)。

## 产品使用目标

建立画板，加入图片、中文文字和手绘，使用位置和连线组织关系，把局部图片收入档案盒，在远处建立其他主题并快速往返。关闭重开后继续编辑，项目传到另一端仍可使用。资料增加时，仍能通过导航、搜索和局部专注找到内容。

## 统一概念

- 画板是包含对象、原图资源和布局的独立项目，管理主页组织这些项目。
- 对象是可独立编辑的图片、文字、笔迹、箭头、关系线、分组、区域或档案盒。
- 原图资源保存实际图片文件，同图多处展示使用不同对象，各自裁剪、位置和批注独立。
- 视图表示查看位置、比例和临时查看条件，移动视图不改变对象布局。
- 分组用于一起操作，区域框用于主题布局，档案盒用于图片收纳。画板列表中的文件夹管理整张画板。
- 自由箭头记录路径，关系连线增加对象绑定；绑定前后保留对象标识、文字和样式。

## 共同交互和数据规则

1. 对象使用稳定标识，保存重开和改名不破坏关系引用。复制创建新标识并重建内部关系。
2. M07 统一维护归属和变换。视觉重叠不改变归属，包含关系不得循环；对象不具有相互冲突的移动归属。
3. 附着批注跟随图片，自由批注保留画板位置。绑定目标在编辑时可见，解除绑定保留当前外观。
4. 专用编辑由所属模块产生操作，通过 M07 的事务一次提交。一次拖动、批量导入或收纳形成一次可理解的撤销步骤。
5. 结构、资源、归属和连接以一致状态保存。裁剪和隐藏不删除原图，仍被对象或恢复记录引用的资源不得提前清理。
6. 当前会话的编辑撤销归 M07，重开后的备份恢复归 M09；视图返回归 M04。
7. 内容模块同时提供自身几何、命中、绘制、版本化编解码与搜索资料适配。M04、M05、M09 分别消费这些接口，不各自维护一套内容真源。
8. 保存错误、资源缺失、格式不支持和硬件能力缺失明确显示。取消或失败不报告为成功，不留下半个联合操作。
9. 两端核心编辑离线可用，先支持可编辑项目文件传递；自动云同步与并发编辑另行设计。

## 档案盒与已有关系

首版档案盒收纳图片及其附着内容，不嵌套，外部关系连接档案盒整体。收纳已有关系的图片时，M03 提出收纳意图，M08 计算端点改接，显示预览并明确确认后，由 M07 将归属和端点变化作为一个事务提交。取消不改变内容，一次撤销恢复完整状态。

改接保留线条标识、文字、样式和不受影响的端点。同一条关系两端都改接同一个盒时，以可编辑回环线保留。图片拖出后连接继续指向盒，可手动重接；保存重开保留实际目标。

解散档案盒可选择保留图片，或连同内容一起删除。操作前预览受影响的盒连接；盒删除时连接随目标移除，需要保留的连接可先重接。撤销恢复相应内容与关系。

## 质量与完整验收

无限画板采用持续扩展的操作体验，实际支持规模通过固定设备与负载验收。测试前规定设备、图片与对象规模、帧耗时、输入延迟、内存、保存打开耗时和恢复目标，目标与实测结果分别记录。

设备覆盖 Windows 键鼠及数位板或笔屏、Android 触摸和主动笔。硬件特性以实际型号、系统与驱动记录为范围。缺少真实设备或模块对接时，对应条目标为待验证或待集成。

联合验收包含混合对象编辑、图片批注、收纳和连线改接、搜索展开盒内结果、隐藏筛选、故障恢复、跨端往返和区域导出。模块单独验证与真实组合场景分别记录。
